# Customer Data Analysis Using Python
# 1. Project Overview

This project focuses on analysing customer data using Python. The main aim is to understand the characteristics of customers and identify useful patterns in areas such as age, gender, monthly income, and customer churn.

The analysis was carried out using Python libraries such as Pandas and Matplotlib.

# 2. Objectives

# The main objectives of this project are to:

Analyse customer demographics.
Group customers into different age categories.
Calculate the average monthly income.
Compare monthly income across different genders.
Calculate the customer churn rate.
Create simple visualisations to make the findings easier to understand.
# 3. Tools and Technologies

The following tools and Python libraries were used:

Python
Pandas
Matplotlib
Jupyter Notebook
# 4. Data Analysis
# Age Group Analysis

Customers were grouped into three categories:

Young: 0–35 years
Middle-Age: 35–45 years
Old: 45 years and above

This makes it easier to compare customer characteristics across different age groups.

# Monthly Income by Age Group

The average monthly income was calculated for each age group and arranged from the highest to the lowest income.

# Monthly Income by Gender

The average monthly income was also calculated and compared between genders using a bar chart.

# Churn Rate

The churn rate was calculated to determine the percentage of customers who have stopped using the service.

# 5. Visualisation

Matplotlib was used to create charts that make the analysis easier to understand.

Examples include:

Monthly Income by Gender
Monthly Income by Age Group
Customer Churn Analysis
# 6. Key Findings

The analysis helps to identify differences in income across age groups and genders. It also provides an understanding of the proportion of customers who have churned.

The findings can help businesses better understand their customers and make informed decisions.

# 7. Conclusion

This project demonstrates how Python can be used to perform basic customer data analysis. By using Pandas for data manipulation and Matplotlib for visualisation, useful information can be extracted from customer data.

The project also provides practical experience in data cleaning, grouping, aggregation, and visualisation, which are important skills for a data analyst.
